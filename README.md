# Ruslaanchik

Приватный Minecraft-сервер Ruslaanchik. **Minecraft 1.21.1 · NeoForge 21.1.250 · Java 21.**

Сервер: `mc-ruslaanchik.ebash.id`.

[Twitch](https://www.twitch.tv/ruslaanchik) · [Telegram](https://t.me/Ruslaanchik_gg) · [DonationAlerts](https://www.donationalerts.com/r/ruslaanchik)

## Установка

Установите совместимый [AntHub](https://github.com/abrosdaniel/anthub) в отдельный профиль Minecraft с указанным NeoForge. В AntHub добавьте `https://github.com/abrosdaniel/mc-ruslaanchik`, выберите компоненты и подтвердите установку. После подготовки закройте игру по подсказке AntHub, дождитесь применения файлов и запустите профиль снова.

Для доступа сообщите администрации игровой ник. Не передавайте другим данные AuthLogic.

## Структура

- `anthub.json` — название, версия, единственный сервер, Minecraft/NeoForge и все компоненты сборки.
- `files/config/` — конфиги, устанавливаемые в игровую папку `config/`.
- `content/rules.md` — условия доступа и правила.
- `content/news/` — новости в Markdown.
- `.github/`, `tooling/`, `schemas/` — проверка и публикация из автономного шаблона `anthub/template`. Все необходимые служебные файлы уже входят в эту папку; экспорт и копирование из других папок AntHub не требуются.

Название берётся из `name`. Описание, иконка и онлайн загружаются непосредственно с Minecraft-сервера.

## Обновление сборки

1. Измените компоненты или файлы. Для модов используйте точные HTTPS URL; для своих файлов — `repositoryPath`. При изменении файла с явно заданным `sha256` обновите контрольную сумму.
2. Увеличьте верхнеуровневое `version` в `anthub.json`.
3. Сделайте commit и push в основную ветку. Дождитесь успешного **Publish pack** в Actions.

Workflow автоматически создаёт релиз `pack-v<version>` и файл `channels/stable.json`. Папка `channels/` отсутствует в исходном шаблоне и появится после публикации. Её не нужно создавать вручную. Старые номера версий не переиспользуйте.

Secrets и ключи подписи не нужны: GitHub выдаёт `GITHUB_TOKEN` автоматически. Правила ветки должны разрешать workflow публикацию файлов канала. После fork включите Actions при необходимости. При сбое проверьте журнал и используйте **Re-run failed jobs**.

## Компоненты и настройки

Обязательные компоненты устанавливаются всегда. Необязательные изначально отмечены, но пользователь может отключить их; зависимости и конфликты учитываются по ID компонентов.

Моды используют `enforce`, настройки — `preserve`: пользовательские изменения настроек сохраняются. Эти значения подставляются автоматически. Версии файлов в этой сборке закреплены явно. Серверные моды администратор устанавливает отдельно.

## Локальная проверка

```sh
python -m pip install -r tooling/requirements.txt
python tooling/anthub.py validate .
```

## Совместимость исходной сборки

Версии модов сохранены. Закреплённый Iris `1.8.14-beta.1+1.21.1-neoforge` объявляет внутри JAR диапазон Minecraft `[1.21,1.21.1)`, исключающий 1.21.1. Перед выпуском проверьте запуск с Iris; при ошибке отключите необязательный компонент или подберите исправленную версию. Валидация проекта не заменяет проверку запуска игры.
